## Color Breakdown

### Primary Colors
- **Header Gradient:** `#667eea` (left) → `#764ba2` (right)
  - Rich purple gradient creating premium look
  - Applies to header background and CTA button

- **Text Primary:** `#2c3e50` (dark blue-gray)
  - Headings and important text
  - Professional and readable

- **Text Secondary:** `#555` (medium gray)
  - Body text and descriptions
  - Good contrast for readability

- **Link Color:** `#667eea` (matching header)
  - Maintains brand consistency
  - Clear visual hierarchy

### Support Colors
- **Warning/Notice Background:** `#fff3cd` (light yellow)
  - Expiration notice background
  - Complements without being jarring

- **Info Box Background:** `#f0f7ff` (light blue)
  - Troubleshooting section
  - Light and informative

- **Neutral Background:** `#f8f9fa` (light gray)
  - Steps section
  - Footer background
  - Subtle and clean

### Shadow Effects
- **Button Shadow:** `0 4px 15px rgba(102, 126, 234, 0.4)`
  - Subtle, maintains purple theme
  - Creates depth without being overwhelming

- **Container Shadow:** `0 10px 40px rgba(0, 0, 0, 0.15)`
  - Gives email card a lifted appearance
  - Works well on white background

## Typography

### Font Stack
```
Primary: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
Fallback: System fonts for maximum compatibility
```

### Font Sizes
- **Header H1:** `28px` (Desktop) / `24px` (Mobile)
- **Greeting:** `16px` (bold, 600)
- **Body Text:** `15px` (normal)
- **Small Text:** `13px` (timestamps, notices)
- **Tiny Text:** `12px` (footer, links)
- **Code/Link:** `12px` monospace

### Font Weights
- **Bold (700):** Main headings
- **Semibold (600):** Section titles, greeting
- **Normal (400):** Body text
- **Light (300):** Taglines, subtitles

## Button Styling

### Default State
```
Background: gradient (#667eea → #764ba2)

Padding: 15px 45px (desktop) / 12px 35px (mobile)
Border Radius: 6px
Font Size: 15px
Font Weight: 600

```

### Hover State
```
Transform: translateY(-2px) [subtle lift]

Duration: 0.2s transition
```

## Key Design Elements

### 1. **Header Section** (Eye-catching)
- Gradient background immediately establishes brand
- Logo/emoji creates visual interest

- Generous whitespace

  - Primary CTA button

### 3. **Expiration Notice** (Important)
- Highlighted with yellow background
- Clock emoji (⏱) for visual scanning
- Clear deadline specified
- Instructions for next steps if expired

### 4. **Footer** (Professional)**
- Company branding
- Social media links
- Legal footer
- Creates trust and legitimacy

## Animation & Interactivity

### CTA Button Hover
```css
transition: transform 0.2s, box-shadow 0.2s;
:hover {
  transform: translateY(-2px);
  box-shadow: 0 6px 20px rgba(102, 126, 234, 0.6);
}
```

### Design Philosophy
- Subtle animation (only 2px movement)
- Quick response (0.2s duration)
- Doesn't overwhelm or distract
- Improves perceived interactivity

### Mobile Clients: A-Grade ✅
- iPhone Mail
- Gmail App (iOS/Android)
- Outlook Mobile
- Samsung Mail

### Things That Work Everywhere
- All text and typography
- Button functionality (works as link)
- Image logo
- Colors (may vary slightly)

### Things With Limited Support
- Gradient backgrounds (might display as solid fallback)
- Box shadows (may not display in some clients)
- CSS animations (not in email)
- Custom fonts (fallback to system fonts)

When testing the email, verify:

✅ **Visual**
- [ ] Logo displays correctly (or emoji fallback)
- [ ] Gradient appears (or solid color fallback)
- [ ] Text is readable
- [ ] Button appears clickable
- [ ] Spacing looks balanced
- [ ] No text overlap
- [ ] Footer is visible

✅ **Functional**
- [ ] All links work
- [ ] CTA button links to verification URL
- [ ] Plain text link works
- [ ] Social links work (if configured)

✅ **Mobile**
- [ ] Text is readable on small screen
- [ ] Button is full width (mobile)

✅ **Content**
- [ ] User's name displays correctly
