## 🚀 Quick Steps

### For Admin/Instructor - To CREATE & SCHEDULE

```
1. Admin → Courses → {Course} → Live Sessions → Create
   
2. Fill form:
   ├─ Title: "Your Class Title"
   ├─ Facilitator: Your Name
   ├─ Start Time: When class starts
   ├─ End Time: When class ends
   ├─ Session Type: Jitsi Meet
   └─ Jitsi Room: AIVibeCoding112  ← Your custom name
   
3. Click "Schedule Session" ✅
```

### For Students - To JOIN

```
1. Dashboard → Courses → {Course} → Live Sessions
   
2. Click: Active Session [LIVE NOW]
   
3. Jitsi Meeting automatically loads ✅
   
4. Browser asks: "Allow camera/microphone?"
   → Click "Allow"
   
5. You're in! Start the meeting 🎉
```
