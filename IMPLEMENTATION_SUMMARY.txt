🔧 TECHNICAL DETAILS
════════════════════════════════════════════════════════════════

DateTime Format Pipeline:
  User Input (Visual/Manual) → DD/MM/YYYY HH:mm
  Flatpickr Processing → Display format
  Form Submission → Hidden input stores DD/MM/YYYY HH:mm
  Backend Validation → date_format:d/m/Y H:i
  Carbon Parsing → createFromFormat('d/m/Y H:i', \)
  Database Storage → ISO format (2026-10-16 15:00:00)

Flatpickr Configuration:
  • enableTime: true (time picker enabled)
  • dateFormat: "d/m/Y H:i" (DD/MM/YYYY HH:mm)
  • time_24hr: true (24-hour format)
  • minuteIncrement: 1 (1-minute intervals)
  • allowInput: true (manual typing allowed)
  • clickOpens: true (click opens calendar)
  • closeOnSelect: true (auto-close on selection)
  • appendTo: document.body (proper z-index)
  • position: 'auto' (adaptive positioning)

Error Handling:
  • Retry logic: Checks typeof flatpickr every 100ms
  • Try-catch blocks: All flatpickr() calls wrapped
  • Fallback: Manual text entry always works
  • Graceful degradation: Works without calendar
